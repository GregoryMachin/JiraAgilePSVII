# about_JiraAgilePSVII

## SHORT DESCRIPTION

JiraAgilePSVII extends JiraPSVII with Jira Agile board, sprint, and epic automation commands.

## LONG DESCRIPTION

Use JiraAgilePSVII when you need Jira Software Agile REST operations from PowerShell.
